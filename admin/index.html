📋 Come gestire i prodotti:

  1. Clicca sul pulsante qui sotto per aprire GitHub
  2. Vai nella cartella products
  3. Clicca "Add file" → "Create new file"
  4. Nome file: nome-prodotto.json
  5. Copia e incolla il template JSON qui sotto
  6. Modifica con i dati del tuo prodotto
  7. Clicca "Commit new file"
